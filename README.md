# Margin–Line Length Coupling and Reading Cognitive Load

This repository contains the reproducible workflow for the study:

**From Ji Bai Dang Hei to Margin–Line Length Covariation: A Dose–Response Analysis of Coupled Layout Parameters on Reading Cognitive Load**

## Overview

- Experiment 1: within-subject four-level margin design (N = 40)
- Experiment 2: text complexity modulation (N = 50)
- Experiment 3: ablation of line spacing and line length (N = 40)
- Follow-up decoupling validation (Condition M, N = 30)
- No physiological data were collected. The study uses questionnaires, comprehension questions, and behavioral ratings only.
- Ethics: minimal-risk anonymous assessment; formal ethics review not required under institutional policy. See `ethics_statement.md`.
